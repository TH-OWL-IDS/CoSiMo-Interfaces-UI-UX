# 003 — CoSiMo Character Consistency Across Interfaces

**Date:** 2026-05-28
**Status:** Accepted

## Context

CoSiMo appears across multiple interfaces — app, web app, cabin display, and physical gadgets — developed by different teams. Without a shared principle, the character risks drifting across surfaces.

## Decision

CoSiMo is one character everywhere. The same visual mark language (see [001](001-cosimo-character-visual-identity.md)), the same emotional states, and the same name are used across all interfaces, regardless of who builds them. Adaptations for screen size or medium are allowed — changes to the character itself are not.

## Consequences

- Users experience CoSiMo as a single, continuous presence across the journey.
- Interface teams must align on character representation before implementing.
- Any extension to the character (new emotional states, new character types) must be decided centrally and applied across all interfaces.
